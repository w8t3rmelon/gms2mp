# midimaker: 2!
(formerly gms2mp)

a simple midi playback extension for gamemaker powered by 
[fluidsynth](https://github.com/fluidsynth/fluidsynth)

## disclaimer
this extension is still actively in development so there may be some bugs /
breaking changes along the way

## compiling

### prerequisites
- [cmake](https://cmake.org/)
- [vcpkg](https://github.com/microsoft/vcpkg)
- a C compiler
    - msvc (the one that comes with visual studio) or gcc/clang on msys2 should
    work fine on windows
    - gcc/clang (idk about other compilers) should work fine on linux
- a build tool like ninja / gnu make / anything cmake supports
